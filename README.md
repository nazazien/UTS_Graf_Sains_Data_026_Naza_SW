## Deskripsi Proyek

Repository ini berisi pengerjaan Ujian Tengah Semester (UTS)
mata kuliah Graf Sains Data menggunakan dataset RetailRocket.

## Isi Repository

- Notebook: implementasi dan analisis pengerjaan UTS.
- `requirements.txt`: daftar library Python yang diperlukan.
- `data/`: dataset dan data hasil pemrosesan.
- `image/`: dokumentasi proses pengerjaan dan hasil visualisasi.

## Menjalankan Notebook

1. Clone repository ini.
2. Siapkan environment Python.
3. Instal dependensi menggunakan `requirements.txt`.
4. Pastikan dataset tersedia pada direktori `data/`.
5. Jalankan notebook secara berurutan.

## Dataset

Dataset yang digunakan adalah RetailRocket E-commerce Dataset.

## Dokumentasi

Bukti pengerjaan dan visualisasi graf tersedia pada folder `image/`.
